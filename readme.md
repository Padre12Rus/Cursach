# Wi-Fi Chat — Приложение для передачи данных по Wi-Fi

![P2P Chat Screenshot](./screenshot.png)

## Описание проекта

Wi-Fi Chat — это кроссплатформенное приложение на Python для передачи текстовых сообщений и файлов между устройствами в локальной беспроводной сети Wi-Fi.

## Принципы работы

1. **Wi-Fi соединение**: передача данных между устройствами в локальной беспроводной сети без центрального сервера.
2. **Асинхронность**: использование `asyncio` для неблокирующей работы сети и GUI.
3. **WebSocket**: транспортный протокол для двунаправленного обмена данными.
4. **Очередь отправки**: внутренний `asyncio.Queue` гарантирует последовательную и надёжную передачу сообщений.
5. **GUI на Tkinter**: лёгкий и переносимый интерфейс для выбора пиров, просмотра истории и отправки сообщений/файлов.

## Входные данные

- **Имя пользователя**: задаётся при первом запуске и сохраняется в `user.json`.
- **IP-адрес и порт (8765)**: используется для подключения к другим пирами в локальной подсети.
- **Файлы и сообщения**: пользователь выбирает текст или файл через диалоговое окно.

## Установка и запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/yourusername/wifi-chat.git
   cd p2p-chat
   ```
2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустить приложение:
   ```bash
   python main.py
   ```

## Технологический стек

- Python 3.8+
- `asyncio`
- `websockets`
- `tkinter` (Tk 8.6+)
- `Pillow` (для отображения изображений)

## Основные возможности

- Отправка и приём текстовых сообщений
- Отправка и приём файлов (до 10 МБ)
- Автоматическое обнаружение пиров в подсети
- Индикация онлайн-статуса с периодическим "ping"
- Дружественный GUI с возможностью смены темы

## Конфигурация

- **user.json**: хранит `{ "username": "Имя пользователя", "theme": "dark|light" }`
- **chat_history.json**: сохраняет историю переписок по каждому пиру

## Тестирование

При запуске запустите два или более экземпляров на разных машинах/окнах. Проверьте:
- Передачу текстовых сообщений
- Передачу различных форматов файлов (изображения, документы)
- Корректное отображение статуса пиров
